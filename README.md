# CSC649: My First Python Experiment

## Description
This program takes a sentence input from the user and calculates the total word count and character count. It also validates if the user provides an empty input.

## How to Run
Run the script using Python in the terminal:
`python main.py`

## Test Results
1. **Normal sentence**: Successfully displayed correct word and character counts.
2. **Empty input**: Successfully detected and displayed "You did not enter a sentence."
3. **Extra spaces**: Handled correctly; word count remained accurate despite extra spaces.

## Limitation
The character count calculation includes all spaces and punctuation marks, not just alphabetical letters."# CSC649_1"
